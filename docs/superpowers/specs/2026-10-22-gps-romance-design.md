# GPS 지도 연애 게임 — 설계 (2026-10-22)

C:\c_b\map(GPS 몬스터 수집 게임)을 복사해 출발한 별개 게임. 지도·GPS·시뮬레이터·국내 영역·AR 카메라 코드를 재사용한다.

## 사용자가 정한 것 (brainstorming, 2026-10-21~22)
- 공략 대상: 여성 캐릭터들. 모두 명확한 성인. 노출·선정 표현 없음. 실존 인물·기존 IP와 닮지 않게.
- 그림체: 미연시(비주얼노벨) 스탠딩 일러스트, 투명 배경. 표정 차분 기본·웃음·부끄러움. Codex GPT 이미지로 만들고 사용자 확인 후 반영.
- 등장 장소: 카카오 장소 검색으로 주변 실제 장소(캐릭터별 단골 유형). 검색이 안 되면 격자 시드 대체 배치.
- 만남 배경: AR 카메라 영상 위에 캐릭터. 카메라가 안 되거나 끄면 장소 유형별 그림(그라데이션) 배경.
- 재만남: 시간 간격(만난 뒤 1시간 쉬고 다른 장소에 다시 나타남).
- 분량: 3명 × 5화. 호감도에 따라 해피/친구 엔딩. 앨범 = 본 표정 일러스트 + 캐릭터당 엔딩 CG 1장.
- 공통: 국내 전역, 시작 위치는 현재 GPS 위치(고정 좌표 없음), 1인용, 서버 없음(localStorage), 지도 사용량 최적화 안 함.

## 등장 규칙 (src/game/placement.ts)
- 시간 창 = 1시간. 캐릭터마다 (캐릭터 id, 창 번호) 시드로 후보 장소 중 하나를 고른다(후보는 장소 id로 정렬해 결정적).
- 후보: 플레이어 반경 1km 안 그 유형의 장소(카카오 Places). 직전에 만난 장소는 뺀다.
- 후보가 없으면(키 없음·Leaflet·검색 실패·결과 0) 500m 격자 칸 시드로 200~600m 떨어진 가상 지점("어딘가의 카페" 같은 이름).
- 플레이어가 400m 넘게 움직이거나 창이 바뀌면 다시 고른다.
- 만난 뒤 1시간은 쉬는 중(지도에 안 나옴, 목록에 남은 시간). 엔딩을 본 캐릭터는 더 나오지 않는다(앨범에서 다시 보기).
- 만남 반경 40m, 정확도 100m 이내(기존 rules.ts 그대로).

## 만남 (src/romance/Meeting.ts)
- 전체 화면 오버레이. 배경 = 후면 카메라(기존 AR 카메라 코드) 또는 장소 유형 그라데이션. 📷 토글.
- 캐릭터 스탠딩은 하단 중앙. 대사창: 이름, 타자 효과, 탭하면 다음 줄(타자 중 탭이면 줄 전체 표시).
- 대사 줄마다 표정(neutral/smile/shy). 선택지 2~3개, 호감도 −5~+10.
- 5화: 호감도 ≥ 60이면 해피 엔딩(엔딩 CG), 아니면 친구 엔딩.
- 중간에 닫으면 그 화는 저장하지 않는다(쉬는 시간도 시작하지 않음).

## 이야기 데이터 (src/romance/story/*.ts)
- `Episode = { lines: Line[] }`, `Line = { who, text, face? } | { choice: [{ text, delta, reply: Line[] }] }`.
- 화 번호 1~5. 5화는 `happy`, `friend` 두 갈래 끝 줄을 가진다.
- 대사의 `{place}`는 만난 장소 이름으로 바뀐다.
